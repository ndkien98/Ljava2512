Đăng nhập trực tiếp qua Keycloak Authorization Server. Phù hợp cho hệ thống doanh nghiệp với nhiều ứng dụng dùng chung một identity.

Tiếp tục với Keycloak
Luồng hoạt động
1 Bạn được redirect sang Keycloak Login Page
2 Chọn: Google / GitHub hoặc đăng nhập bằng username/password nội bộ
3 Keycloak phát sinh JWT Token → redirect về app
4 Spring Boot xác minh chữ ký JWT → cấp quyền theo Roles
Keycloak Server
Đảm bảo Keycloak đang chạy tại http://localhost:8080 và realm uniqlo-realm đã được cấu hình.

Identity Provider

Resource Server — Spring Boot

Xác minh JWT, phân quyền theo Roles, bảo vệ API.
